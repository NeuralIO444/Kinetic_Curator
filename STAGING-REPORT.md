## What shipped (plain language)

Each content and pattern stratum in BUILD now has a small wave toggle on its row, beside the visibility eye. Lit, the stratum's light feeds the trails buffer as it always has; tapped, the wave strikes through, the stratum keeps performing on stage exactly as before, and its trails stop — the buffer remembers only the strata that still feed. The collapsed block says so in words: `no feed` in its amber summary line. The choice saves into the project file and reloads intact: a project saved with a stratum flagged off reopens with the same stratum off and the same trails behaviour, and a project that never touches the toggle saves byte-for-byte as it did before the flag existed. FX and MATH rows get no toggle — they never feed.

## How (specifics)

- **The chain** (the house event path, all five links, mirroring LAYER_TOGGLE_VISIBLE): `Events.LAYER_TOGGLE_FEEDS_ACCUM` (`layer:toggleFeedsAccum`) in eventBus.js → registry entry (`handler: 'wire'`) → wireEventBus dispatch → `A.TOGGLE_LAYER_FEEDS_ACCUM` in applyAction.js → `toggleLayerFeedsAccum` in layersSlice.js. busChain's whole-chain suite proves the new event reaches a real case; eventRegistry's suite proves the registry is complete and honest.
- **The setter** (`layersSlice.js`): a layers-undo entry like its neighbours. Toggling off writes `feedsAccum: false`; toggling back on **deletes the key** — absence is the on state, so store, saved file and contract keep the one shape slice 2 defined, and nothing anywhere spells the flag `true`. On FX/MATH layers it returns `{}` — no key, no undo entry (they never feed; there is nothing to toggle). `duplicateLayer` carries the flag in both copy paths (content + pattern), key-only-while-off, like every other stratum property.
- **The control** (`LayerStack.jsx`): rendered only when `!adj` (content + pattern), after the solo button. Glyph `≈` — waves while feeding; with `.feed-off` (panels.css: opacity 0.45 + line-through) while not. Full words in the title + `aria-label`, state in `aria-pressed`. No new panel, no cluster: one detent on the row, per the design.
- **The confession** (`strataSummary.mjs`): content summaries gain `no feed` after the patch part (inside the existing first-two-parts rule, so the line's shape is unchanged for unflagged strata — every existing pin holds); pattern summaries append ` · no feed`. This is #1409's dish-off rule applied to the new flag: an OFF choice the collapsed block must state.
- **The load carry** (`projectNormalize.js`): `normalizeLayers` assigns `feedsAccum: false` only when the raw layer is content/pattern and the value is exactly `false` — a spelled `true`, a non-boolean, or an FX/MATH flag all load as absence. Assigned **last**, after the type branches, which is where the UI toggle appends it: a save → load → save round trip is byte-stable (found by measurement: my first placement rebuilt the key ahead of `patch` and the byte pin caught the key-order churn; the fix is placement, not a weaker pin).
- **No serializer change:** `serializeProject` already writes the layer list as it stands — the flag rides it while off and is absent while on, no code needed and none added. No layout param was added (the feedsAccum key stays a document-layer field, NOT a layout param — the #1804 hash trap stays avoided). The governor sensor needed no wiring: slice 2 built it over the store's layers.
- **Proof** (`app/src/state/feedsAccumSurface.selfcheck.mjs`, new, manifest-wired after accumFeed — 12 cases): the whole bus chain driven for real (key appears as false, disappears on re-enable, never true); undo restores; FX/MATH no-op (no key, no undo entry, layer byte-unchanged); pattern toggles through the same chain; duplicates inherit (content + pattern); serialize writes exactly one `feedsAccum` key while one stratum is flagged and **none anywhere** while all-on; the round-trip pin (serialize → parse → apply → serialize: layers byte-identical); the normalize edges; the round-tripped document builds slice 2's contract and `accumFeedSelection` names the feeding strata; the summary confession; source pins (the row gates on `!adj`; the setter deletes the key).
