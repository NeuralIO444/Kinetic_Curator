## What shipped (plain language)

A scene can now say "this stratum doesn't feed the trails." When any stratum is flagged off, the accumulation buffer is fed **only the strata that feed** — drawn again through the renderer's own seam — so a moth can stop leaving trails while the background plate keeps trailing, and the stage picture does not change at all: the flagged stratum still renders, folds and finishes exactly as before. When nothing is flagged — every existing project — the buffer eats the full composite exactly as it did before this slice, byte for byte (proven, not assumed). The extra partial render the selection costs is measured, declared in the cost registry, and sheddable: under GPU pressure the governor drops the subset render and everything trails until pressure lifts. There is still no performer surface — the BUILD toggle is slice 3 — but the flag's data path is complete: a document layer's `feedsAccum: false` flows through the shared scene-contract builders to both consumers (trail stills and the live loop) with no session state in between.

Evidence: `docs/review/1833/` — `stage.png` (the flagged scene on stage, unchanged), `buffer-all-feed.png` vs `buffer-subset.png` (the buffer holds only the feeding stratum's marks, in raw pre-FX colour), `README.md` (byte-level results + the cost table and method).

## How (specifics)

- **The flag** (`app/src/gl/sceneContract.js`): `buildSceneContract` carries a document layer's `feedsAccum: false` onto content and pattern contract layers — read from the resolved layer's source layer or the document layer (the matte #189 precedent). **The key exists only while off**: an unflagged scene's contract is byte-identical to the pre-#1806 one (hash stability; the squash/cellShed precedent), and spelling `feedsAccum: true` builds the identical contract. `assertSceneContract` rejects the key anywhere else (if present it must be exactly `false`, on a content/pattern layer only). No layout param was added — the DEFAULT_LAYOUT_PARAMS hash trap from #1804 is avoided by keeping the field on the document layer, in the project-JSON shape slice 3 will author.
- **The derivation** (`app/src/gl/renderer.mjs`): `accumFeedSelection(contract)` — null while every feed-capable stratum feeds (the byte-identical historical path), else the feeding ids in compositeOrder via slice 1's `accumFeedLayers` (one capability definition, shared). Possibly `[]`: everything off feeds the buffer transparency.
- **Still sequence** (`renderAccumSequence`): derives the selection per frame from the frame's own contract — no new option, so `accumStill`/studio parity comes free through the shared contract builder. The subset renders into a lazily allocated second target set, freed in `finally`. The full render still runs every frame (its finish chains land on the buffer as before); only the step's input changes: `accum.step(subFrame.tex, params)`.
- **Live loop** (`app/src/gl/liveLoop.mjs` + the live renderer wrapper `renderAccumInputFrame` in renderer.mjs): after `renderMixedFrame`, when a selection is live and the governor has not shed it, the loop renders the subset into a dedicated target set (live size, freed on dispose) and steps the buffer with it. Three honest fallbacks feed the composite instead, each commented at the site: no selection (the default), a palette-dissolve frame (`typeof mix === 'number'` — a dissolve blends two whole scenes that were never rendered as subsets), and a subset render that throws (logged; one frame of lost selection beats a lost frame of show).
- **Slice-1 flag (a) — pattern sweep ownership** (renderer.mjs): in `renderFrameInto`, an `accumInput` render now seeds its seen set from the full render's (`patternSeen = accumInput ? new Set(patternSeen) : new Set()`) instead of resetting it, so a subset render never frees an unselected pattern's texture mid-frame. The pinned line `sweepPatternTextures(); // #1098` (regex-pinned by patternRender.selfcheck) is untouched; the fix is pinned by a source assertion in the new suite.
- **Slice-1 flag (b) — matte ruling:** a feeding stratum renders into the buffer **exactly as on stage — matte included, even when the matte's source stratum does not feed.** The source lends its shape, never its light. The renderer already behaved this way via the seam; slice 2 confirms it as the ruling and pins it in the proof suite (below).
- **Slice-1 flag (c) — cost, declared + measured, and the shed rung:**
  - `registerCostTier('gl/accum-feed', { tier: 0, … })` (renderer.mjs) — tier 0 per the #740 FXAA precedent (shed by its own governor cut, not by tier; tier 1 would break costTiers' pinned tier-1 set of exactly the 9 ACCUM passes). No row in measuredCosts.mjs: its rows are pass-sweep draws, and a scene render is not one — a row there would corrupt its method. Measured on the parity bench scene (two strata, 19 instances, 512×512, page-side loops, medians of 7): subset 641.9 ms vs full 903.7 ms SwiftShader wall — ratio **0.71**. timeMs 3.5 is the author's estimate from that ratio against the iPad render cap (FRAME_BUDGETS 5.0 ms), derivation in the registration's comment; hardware re-bless supersedes. Full table: `docs/review/1833/README.md`.
  - **Governor cut 1.47** (`app/src/hooks/governorCuts.js`, `usePerformanceGovernor.js`, `app/src/state/slices/globalSlice.js`, `app/src/components/TapeCounter.jsx`): kind `accumFeed`, placed after the feedback warp (1.45) and before the creature count (1.5) — its ACCUM family first, it costs the presented frame nothing, and it drops a whole partial render ahead of cut 3's tier mechanism, per #1806's cost paragraph. Opt-in gating (`accumFeedActive === true && !accumFeedShed`) so legacy callers and ladder walks see the pre-#1806 ladder unchanged. The hook's sensor derives activity with the renderer's own `accumFeedSelection` over the store's layers, so sensor and recipe cannot disagree. State: `accumFeedShed` + setter beside `feedbackWarpShed`, reset in applyProject. SHED_STEPS and the governor event log deliberately NOT extended (the fractional-cut precedent; the hook's recordCutEvent guard skips unknown kinds safely — its comment now names accumFeed). The badge reports it: `shedSummary` gains 'accum feed — all strata', wired through TapeCounter.
- **Proof** (`app/src/gl/accumFeed.selfcheck.mjs`, new, manifest-wired — 15 cases):
  - Node: the derivation (null/ids/empty/fx-flag-blind), the contract carry (key-only-while-off, explicit-on byte-identical contract, pattern carry), the validator, the sweep source pin, the governor rung (fires once, order feedbackWarp < accumFeed < creatureCount, gating, restore truth table, badge), the cost declaration.
  - Browser (slice-1 scene): **default byte-identical** sequences (unflagged vs explicit-on); **zero trail** — a flagged-off stratum's sequence buffer matches the scene-without-it buffer to worst Δ 1 LSB; **both-off** holds the begin background (uniform to the resolve dither) with no FX leak; **mirror parity on both paths** — the JS mirror stepped on the composite frame and on the subset frame each matches the GPU probe to ≤3 LSB; **the matte ruling** — matted subset never exceeds the plain subset, alpha sum falls 320,746 → 36,619, and zero light survives outside the non-feeding source's footprint.
  - Two assertions were re-derived from measurement during this build, recorded here for honesty: sequence outputs resolve ACES+dithered (only one-shot renders take the raw data-space resolve), so the zero-trail proof lives in sequence space, not probe space; and "flag off ≡ layer removed" holds for sequences but not one-shot stills (a full still paints the palette backdrop; a subset render never does — slice 1's seam rule).
