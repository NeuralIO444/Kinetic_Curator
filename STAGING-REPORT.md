## What was built

- **`src/curator/roomDither.js`** (new, pure — no clock, no randomness, no DOM) — the shared pipeline and the two sources.
  - *The dither stage (shared):* ordered-Bayer quantization of a shade field into a few levels. Bayer, never error-diffusion: a settled face is a settled picture (06 rejects Floyd–Steinberg for exactly this). Levels are then read as colours (Davis) or glyphs (LOIS).
  - *Davis's source:* the seed's own sigil geometry (`davisSigil.js`, untouched) rasterized once per seed into ornament and ring fields, folded out by the same 8-fold mirror the sigil draws with. Per frame the component samples it rotated by the turned angle and scaled by the breath, so the dither stays stable while the source moves. His colour ramp is built from the `--kc-davis` token at runtime (five stops, dark to a hot centre).
  - *LOIS's source:* a shaded face construction — head and hair mass, a lit face oval that falls off toward the jaw, eye slots and brows as dark marks, a faint nose, a mouth slot on a curve. Each state's parameter set (eye angle/opening, brow tilt, mouth curve/opening, tint, glyph set) bends the construction; features read as gaps in the glyph mass, as the mockup reads them.
- **`src/panels/directors/RoomFaces.jsx`** (rewritten internals) — the canvases and their animation: a small rAF loop throttled to ~9 fps (slow ambient motion only), easing the face parameters toward the current state's set on a change (state changes *animate* as transitions between sets, then settle to breath — 06). LOIS's mind-overlay blend is the seam's old contract kept: her honest canvas under, the requested state's canvas over, cross-faded for one bar by the existing `blendStyles`. Davis turns at the tempo of the code the panel hands him (`davisSigil`'s tempo table, unchanged), still and dim with no state. Both faces read their colours from the design tokens at runtime.
- **CSS** (`styles/panels.css`): `.codec-dither` — the canvas shown at the window's 84 px (68 on short windows), `image-rendering: pixelated` so the tier's grid is the picture's resolution; rest-state Davis dimmed to 0.55 as the sigil was. The `.davis-sigil` rules were left exactly as S1 left them.
- **e2e** (`room-codec.spec.js`): the three face tests re-pointed at the dither canvas — same contract as the sigil's tests carried (still at rest, turning in FLOW with frames that change over time, a new seed is a new face, settled still under reduced motion), now asserted on `data-motion` + canvas pixels instead of the CSS rotation.

## How state maps to each face (the honest-signals path)

- **Davis** receives `{ seed, code }` from the panel exactly as before: the rosette is that seed's geometry; the code picks the parameter set — spin rate from the tempo table (FLOW 14 s … STUCK 40 s, UGLY 4 s), spin direction, source density and ring gain (below). No state → no spin, no breath, dimmer raster: rest reads as rest.
- **LOIS** receives the honest face string + mind overlay, as before. The honest code is recovered from the face (the four honest faces are unique strings) and picks her parameter set; the overlay's state (canonical, CUT, or invented) picks the overlay canvas's set — invented states derive a *stable* set from the state id's hash, the same trick `mindFace`'s micro-expression pick uses, so an invented state wears the same dithered face every time it appears.
- **The faces perform nothing the persona isn't in:** every input is the panel's already-honest state resolution (the loisActivity feed + the mind overlay, both recorded in takes). No timers invent expression here; the ambient loop only turns/breathes what a real state set in motion.
- **Parameter sets (06's "state = parameters"):** Davis — FLOW spin +1 · density 1 · rings 1; SEEDLING 0.85/0.9; BLOOM 1.12/1.15 (a bloom is fuller and rings harder); STUCK 0.7/0.5 (thinned, rings faded, barely turning at its 40 s tempo); UGLY density 1.05 and **spin −1** (sifting turns against the grain). LOIS — eye angle −8°…+12°, eye opening, brow tilt, mouth curve/opening per state; tint (how far her red enters, strongest in the darks where the face's structure is): VIBE 0.10, NOD 0.14, BURN 0.38, CUT 0.45, AWAY 0.03 with `dim` 0.35 — AWAY honestly *fades* rather than performing.

## Where tier / resolution is decided

- §06's law is *tier = resolution*: the grid (cells across the window) is picked from `DITHER_GRIDS` = tier 1: 12, 2: 21, 3: 28, 4: 42. The tier is the persona's own engagement tier from the presence view (`mindPresenceLive`'s published rows — the same source the dev panel reads; tier is each persona's *peak* tier in `mindEngage`, so while a persona is in **cool-down** (score below her floor — quieter, softer by Mind law) she renders one grid coarser, floor tier 1. Before the presence driver publishes, faces render at tier 1 unmodulated — the honest floor. The tier drives only resolution: it is never displayed, and the faces' state is untouched by it.
- **Vibe modulation (06):** contrast from the persona's own seasonal modulation (the presence row's `mod.intensity`); warmth from the session reading — moonlight warms, summer warms, winter cools — bending Davis's mid-ramp stops and LOIS's paper. No reading → no bend (`vibeBend` returns the unmodulated pair; never a substitute reading, `mindZodiac`'s law).
