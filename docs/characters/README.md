## House rules for all three

- No state is driven by a timer pretending to have an opinion. Every reaction comes from a measured signal.
- Visibility contracts are absolute. The Queen is never caught.
- Strong disagreement between Directors is always respectful.
- Silence is the default.
- Degrade by reduction.
