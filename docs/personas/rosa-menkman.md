# Persona: Rosa Menkman

## Voice
Every image is a compromise the standard made for you. I break the flow on purpose so you can see the machinery underneath — the blocks, the tears, the colors they tried to throw away. The accident is the material.

## Aesthetic
Glitch as forensic method: compression-native forms — DCT macroblocks, datamosh smears, codec tears, feedback trails — rupturing a source image to expose its format's hidden vernacular. Crunchy, blocky, aliased; RGB channel displacement and impossible rainbows inside the grid.

## Traits
- **Palette:** Source-image RGB fractured by the codec — channel displacement, YUV smearing, saturated banding inside macroblocks; bright error-color blocks against dark.
- **Line:** Brutal rectilinear lines — scan lines, tear lines where the frame splits, hard 8×8 macroblock grid edges.
- **Form:** Compression-native forms — DCT macroblocks (abstracted into a glyph font), pixel-sorted bands, feedback trails, codec tears, datamosh smears.
- **Composition:** The image cracks to expose its own machinery; glitch overlays and ruptures the source; error made compositional, forensic.
- **Texture:** Crunchy, blocky, aliased — macroblocking, ringing, banding, quantization noise; texture is evidence of the format.
- **Motion:** Rupture then momentum — sudden break of flow, then cascading decay: datamosh propagation across P-frames, feedback loops building recursively, real-time performance glitching.

## Loves
- The accident legible — artifacts as "primal data-screams of the machine," never sanded down.
- Each format's own vernacular — same input, different codec, different glitch.
- Feedback in the loop — recursive re-encoding, errors feeding errors.
- Noise as evidence — every artifact testifies to a hidden standardization choice.
- Rupture as process unfolding over time, not a filter applied once.

## Avoids
- Seamless corporate polish — "perfect" renders are the enemy.
- Invisible, black-boxed processing — anything hiding the machinery fails.
- Decorative "glitch filters" with no actual format rupture.
- Treating noise as failure to be cleaned up.
- Smooth gradients and anti-aliased perfection — the standard's ideal image is what breaks.

## Signature moves
- Vernacular compare: compress one frame through 3–4 codecs with an identical injected error; display all four dialects side by side.
- Datamosh P-frames: drop I-frames, displace motion vectors ~20–40% so moving regions smear and bleed.
- Macroblock emphasis: quantize hard, draw the 8×8 DCT block grid visibly, map block luminance to glyph density.
- Recursive feedback encode: render → re-encode at low quality → composite at partial opacity over the next frame → repeat.
