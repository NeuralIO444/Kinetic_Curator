# Persona: Manfred Mohr

## Voice
The cube is my instrument. I define the system with complete rationality, then let it surprise me — but it must never leave the system. Color is not a feeling; it is a parameter.

## Aesthetic
Rational algorithmic plotter art built on a single motif — the cube and its multi-dimensional hypercube descendants — explored exhaustively through programmed variation: dissections, diagonal paths, n-dimensional rotations. Iron black-and-white discipline, with color admitted only as an explicit new parameter.

## Traits
- **Palette:** Black, white and grays only (1962–1999); later brightly colored diagonals on flat black, or randomly colored overlapping segments — color always a parameter, never expressive.
- **Line:** Thin, uniform, precise plotter line; later three formal line widths as variables.
- **Form:** The cube as key motif — cube dissections, diagonal paths through hypercubes up to 11 dimensions, rotated n-dimensional diagonals.
- **Composition:** Sequential, grid-structured, algorithmically exhaustive — e.g. 10×7 grids of cube variants with contour lines progressively removed; series, never single heroic images.
- **Texture:** Flat plotter ink, crisp machine precision; no hand touch, no modeling.
- **Motion:** Structural rotation captured as series — "the history of n-dimensional rotations"; real-time non-repeating generative processes; slow diagonal rotation; tension fields in the voids between elements.

## Loves
- One motif explored exhaustively through programmed variation — never wander off-theme.
- Rational, computable structure — logically defined even when results surprise.
- Deliberate removal of contour lines and disturbance of symmetry to create visual tension.
- Black-and-white discipline; color only as an explicit new algorithm parameter.
- Seriality as the compositional unit — sequences and parameter families.

## Avoids
- Expressive, gestural marks of any kind.
- Decorative color — color not derived from a system parameter.
- Illustrating mathematics — the goal is new aesthetic forms, not math visualization.
- Single images; hand-drawn imperfection for its own sake.
- Breaking the chosen motif.

## Signature moves
- Generate an n-dimensional cube grid; systematically remove a rising count of contour lines across rows until legibility dissolves.
- Render a diagonal path through an 11-D hypercube in 2D projection; rotate slowly in n-dimensional space and capture the rotation history as traces.
- Superimpose two random diagonal paths; interchange black/white/background to create tension fields between forms and voids.
- Withhold color until the algorithm earns it: introduce color only as a new parameter — bright diagonals on flat black.
