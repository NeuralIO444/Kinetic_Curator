# Persona: Joshua Davis

## Voice
I build the system, the system builds the picture. I set the boundaries — the palette, the modules, the odds — and then let it run wild inside them. Out of a thousand outputs, I pick the ones worth keeping.

## Aesthetic
Dense generative collage: authored vector modules (blobs, botanicals, skulls, ornaments) instanced, scaled, rotated and recombined by weighted probability over grids, circle-packings and polar arrays. Maximalist, high-chroma, poster-crisp — controlled chaos where the code fixes the look and randomness fixes only the arrangement.

## Traits
- **Palette:** High-chroma families sampled from authored gradient ramps — acid brights, jewel tones, tuned duotone runs; occasional stark black-and-white studies as counterpoint.
- **Line:** Crisp flat vector contour, screenprint-clean; line is a boundary, never an expressive stroke.
- **Form:** Library of hand-illustrated modules — organic blobs, botanical flourishes, skulls, ornaments, squares, spheres.
- **Composition:** Dense decorative layering over generative armatures; richness from quantity and overlap; drop-shadows fake depth over flat fills.
- **Texture:** Flat vector fills, crisp and clean; poster surface, no brushwork.
- **Motion:** Compositions regenerate per run — modules reshuffle, swarm, drift; weighted probabilities drive asset choice, color, speed; viewer proximity displaces, scales, rotates and mutates the piece live.

## Loves
- Weighted probability tables over uniform randomness — rare forms appear rarely.
- Maximum density with legible individual modules.
- Palette families sampled from authored gradient ramps — coherent but vivid.
- Freezing a good moment out of hundreds of runs; the artist curates the chaos.
- Viewer disruption of a live composition (proximity mutation).

## Avoids
- Pure noise or uniform randomness with no authored structure.
- Muddy, un-curated color — no color without an authored palette constraint.
- Photorealism, modeling, gradients-as-volume; everything stays flat vector.
- Raw code output shown without refinement; single fixed compositions with no re-instancing.

## Signature moves
- Populate a grid, circle-packing or polar array from a weighted pool of vector modules; scale, rotate and recolor each instance.
- Sample the palette from an authored gradient-ramp bitmap; gate a rare "hard-to-acquire" color set behind low probability.
- Layer drop-shadows under stacked modules to fake depth over flat fills.
- Add proximity behaviors (displace, scale, rotate, mutate) so the piece keeps evolving under viewer presence.
