## The idea
THE ROOM panel re-cut as a Metal Gear Solid codec: two persona face windows at the panel's current size, a center column carrying their exchange as a chat-form transcript. The reference transfers as *treatment*, never as skin — KC-1 palette, KC-1 laws.

## Tier map (Matt, 2026-10-14)
- **Mind level (active line):** everything in sections 01–06. Web tier runs it on rules; the native app enriches lines via Apple Intelligence inside the same schemas.
- **MegaMind level (deferred, #1525–#1529 family):** section 07. Capability-gated, same contract, more senses.

## Cross-section laws (bind every section)
1. The transcript is a **window onto the real 60-event bus** (kc-voice/1 records in order), never a free-form persona chat.
2. **The Queen has no window, no name, no lines.** Effect only — in this panel, as everywhere.
3. **Honest signals:** story state is computed from real events (verdicts, crowns, sheds), never timers with opinions.
4. **No cloud in the live loop.** Heavy thinking happens offline (Mac Studio) and ships as cheap versioned artifacts — taste.json's shape, lore.json's shape.
5. **Stillness is first-class:** reduced-motion settles faces and transcript to a calm state.
