# Synthetic biology — deferred vocabulary

Not a wet lab. Not a feature. A map so the Studio labs ([ASSET_LAB](ASSET_LAB.md), [CHIP_LAB](CHIP_LAB.md)) steal the *stack*, not the costume.

**Embargo:** [EMBARGO.md](EMBARGO.md).

## Stack

```text
part     plate / BioBrick           locker SVG
device   species or voice genome    lab dish
system   show                       Perform
chassis  track + voice / mode       host context
burden   growth cost                tape / TAPE FULL
evolve   directed evolution         dish N breaths, keep / fork
```

Real field: parts → devices → systems on a chassis. Burdensome plasmids get evicted (~20% of measured BioBricks hurt growth; >~45% is unclonable). Same circuit retunes when you change host (RBS × chassis).

Oxman material ecology = form *is* metabolism (R/G veins, flap, hunger). Not PHA in the browser.

## Rules for KC-1

1. Chassis ≠ plate. Drop one species onto Migration and onto Parade.
2. Burden = tape. A genome that needs UNCAPPED + UV + ACCUM on LEAN is unclonable. Preflight refuses.
3. Devices stay the named few: cruise / flock / orbit / scatter + hunger / mold / pigment. Quorum is FIELD. No Hill-function solver.
4. Evolve is keep/fork, not backprop.
5. Every species/voice exposes the same four numbers or it is not a part.
