## What shipped

- **The kana pack** — `app/src/data/assets/assets-kana.js`, generated by the new
  `scripts/gen-kana.mjs`, which mirrors the existing letterform bake
  (`scripts/gen-letterforms.mjs`): opentype.js glyph outlines as path data only
  (never `<text>`), centered on the 100×100 viewBox, 'あ' body height = 80 units
  (the letterform pack's reference convention). The font file is never committed.
  - Bake font: **Zen Kaku Gothic New Bold** (SIL Open Font License 1.1).
  - **163 stamps**: hiragana 81 + katakana 82 = per script 46 basic + **25
    dakuten/handakuten** + 10 small, plus the katakana long-vowel mark ー
    (`typ_k_long`). Ids `typ_h_<slug>` / `typ_k_<slug>`.
  - **Dakuten call: INCLUDED.** They are separate codepoints that bake through
    the identical pattern with zero missing glyphs, so the "only if clean"
    condition is met.
- **Catalogue** — the pack joins `ASSETS` after the authored bake, on the
  creature citizen's road (`app/src/data/assets/index.js`): `ASSETS` 313 → 476,
  `ASSETS_AUTHORED` unchanged at 312, so no region/traits bake names them.
  The census measures them and the stage atlas resolves them.
- **Taxonomy** — `assetStyle.js`: the raw tags `kana`/`hiragana`/`katakana`
  canonicalize under `letter`, with the Latin letterforms. Kana records derive
  family `letterforms` by the `typ` prefix, exactly like `typ_A`.
- **FIELD wiring**
  - `poets/teijo.js`: every Teijo piece gains a `kanaLines` face (4 pieces),
    each line mapping to kana stamps and clearing the poem threshold (≥12).
  - `poets/placement.js`: a glyph resolver (`stampIdForGlyph`) covers kana +
    Latin; kana advance widths measured from the baked paths.
  - `poets/fieldForm.js`: `gateFieldForm` accepts kana stamps only under the
    affirmed kana context (`allowKana`) with glyph↔id agreement;
    `fieldDealReport` places `kanaLines` when the decision carries the kana
    script and stamps the form `script: 'kana'`; `sanitizeFieldForm` refuses
    kana stamps without the declared script, a kana form under another poet,
    and Latin stamps inside a declared kana form.
  - `curator/fieldDirector.js`: `choosePoet` attaches `script: 'kana'` only
    for a Teijo pick in a Japanese context; all other decisions are
    byte-identical to before (conditional spread).
  - `curator/fieldEval.js`: the step wires `lookFamily === 'japanese'` to
    that context. `curator/director.js`: `dealPoet` passes the script through.
  - Silence stays the default: no context, no script, Latin face as before.
- **New suite** — `app/src/poets/fieldKana.selfcheck.mjs`, registered in
  `app/selfcheck.manifest`. Pins the pack (counts, path-only, glyph↔id
  bijection), per-stamp ink under the pinned-font raster (`RESVG_FONT`,
  DejaVu Sans Mono — the #1970 condition), the resolver, the deck, the kana
  deal + document round-trip, the gate's context law, the script wiring, and
  the poem-only surfaces below.

## Found en route (worth knowing)

- `img.pixels` on a Resvg render materializes the buffer **per access** —
  reading it inside a per-pixel loop allocates ~800 MB per glyph and OOMs.
  The new suite reads it once (comment in place). Existing suites already
  cache it; no production code was affected.
